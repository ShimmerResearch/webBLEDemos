# Verisense Demo

A browser-based streaming demo for Verisense devices using the `@shimmerresearch/web-ble` SDK.

The page supports BLE streaming, optional Web Serial connection, operational configuration, and live accel / GSR visualisation.

**Requirements:** Verisense device (IMU or Pulse+), Chrome or Edge

- Canonical source: [`/demos/Verisense/`](./)
- Live demo URL: [https://shimmerresearch.github.io/webBLEDemos/demos/Verisense/](https://shimmerresearch.github.io/webBLEDemos/demos/Verisense/)
