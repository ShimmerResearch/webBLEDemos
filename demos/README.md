# Demos

This folder contains the canonical source for all browser demos in this repository.

## Structure

- `break-gyro/` — Shimmer3R gyro breakout game
- `break-emg/` — Shimmer3R EMG breakout game
- `punch-highG/` — Shimmer3R high-G punch detector
- `brick/` — two-device Shimmer3R gyro game
- `rythmgame-emggyro/` — Shimmer3R EMG + gyro rhythm game
- `video-ppg/` — Shimmer3R PPG visualiser
- `ShimmerCapture/` — Shimmer3R data capture / CSV download tool
- `Verisense/` — Verisense wrist sensor streaming demo

## Contributor note

For backwards compatibility, the old root-level demo folders still exist, but they now only contain redirect `index.html` files so the historic GitHub Pages URLs keep working.

When editing a demo, update the files in this `demos/` folder rather than the root-level redirect folders.
