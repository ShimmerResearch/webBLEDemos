# ShimmerCapture

A browser-based data capture tool for the Shimmer3R sensor platform.

Connect a Shimmer3R over Web Bluetooth, configure sensors and sampling rate, then stream and download the recorded data as a CSV file — no native app or driver required.

**Requirements:** Shimmer3R device, firmware ≥ v1.0.22, Chrome or Edge (Web Bluetooth required)

- Live demo URL: [https://shimmerresearch.github.io/webBLEDemos/ShimmerCapture/](https://shimmerresearch.github.io/webBLEDemos/ShimmerCapture/)
