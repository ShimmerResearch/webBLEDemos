Shimmer3 / Shimmer3R → Consensys Export

Package a logged Shimmer3 or Shimmer3R trial into the Consensys import folder structure, zip it, and share.

Best on a Chromium browser — Google Chrome or Microsoft Edge, kept up to date (Android: Chrome 132+ for folder picking). The Bluetooth "Set RTC" feature needs Web Bluetooth: use Chrome/Edge on Windows/Android, or the Bluefy app on iPhone/iPad (Safari, Chrome-iOS and Firefox can't do Web Bluetooth). No folder picker? Use Option B below to pick the binary files directly.

Device utility — Set Real-Time Clock

Scan, connect and write the current time (host clock) to a Shimmer3 or Shimmer3R real-time clock in one step, before logging. Needs a Web-Bluetooth browser: Chrome/Edge on Windows or Android, or the Bluefy app on iPhone/iPad (Safari and Chrome-for-iOS can't do Web Bluetooth).

1Select the trial data

Option A — pick the whole trial folder (desktop, or Android Chrome 132+). Choose a trial folder (e.g. DefaultTrial_1783578145) containing the device sub-folders (e.g. Shimmer_68DD-000) with the binary files 000, 001, …

Option B — pick the binary file(s) for one device (iPhone/iPad, or older Android where folder picking crashes). Open the device's folder in your Files app and select the 000, 001, … files. The MAC is read from the file; enter the Trial ID yourself since single files carry no folder path.
