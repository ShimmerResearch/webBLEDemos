# ShimmerAPI — legacy Shimmer3R JavaScript source

> **Note:** This folder contains the original ES-module JavaScript source (`shimmer3r.js`) that powered the standalone demo pages.
> It has been superseded by the [`shimmer-ble-sdk/`](../shimmer-ble-sdk/) TypeScript SDK, which exports the same `Shimmer3RClient` class with full type declarations, a Rollup build, and unit tests.
> New integrations should import from the SDK dist instead.
